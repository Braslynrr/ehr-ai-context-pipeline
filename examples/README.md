### Data Traceability

Each example references a specific patient identifier (e.g. `P001`).
The full EHR used for that example can be found under:

data/ehr_<PATIENT_ID>.json

This allows reviewers to inspect the original data used during ingestion
and verify that all responses are grounded in the provided EHR.


> Note: All example outputs are generated by a local LLM using retrieved EHR context.
> They are provided for demonstration purposes only and are not intended for clinical use.
> All EHR files are synthetic and anonymized for demonstration purposes only.
